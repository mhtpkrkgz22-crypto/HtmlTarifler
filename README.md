#FootRecipes
<h1>Food Recipes Website</h1>

<p>
This project is a simple multi-page HTML website that presents different food recipes.
It is designed to practice basic HTML structure, linking pages, and organizing files
using folders.
</p>

<h2>Project Structure</h2>

<p>The project consists of a main page and three recipe pages located in a subfolder.</p>

<ul>
  <li><strong>index.html</strong> – Main page that lists all recipes</li>
  <li><strong>recipes/</strong>
    <ul>
      <li>valikebabi.html</li>
      <li>billurkebabi.html</li>
      <li>omlet.html</li>
    </ul>
  </li>
  <li><strong>images/</strong> – Contains images used on recipe pages</li>
</ul>

<h2>Main Page (index.html)</h2>

<p>
The <strong>index.html</strong> file acts as the homepage of the website.
It contains an ordered list of recipe links that navigate the user to individual recipe pages.
</p>

<ul>
  <li>An <code>&lt;h1&gt;</code> heading for the page title</li>
  <li>An <code>&lt;ol&gt;</code> list to display recipes in order</li>
  <li><code>&lt;a&gt;</code> tags to link to recipe pages</li>
</ul>

<h2>Recipe Pages</h2>

<p>
Each recipe page follows a similar and consistent structure to improve readability
and user experience.
</p>

<h3>Common Elements Used</h3>

<ul>
  <li><code>&lt;h1&gt;</code> for the recipe title</li>
  <li><code>&lt;img&gt;</code> to display the food image</li>
  <li><code>&lt;h3&gt;</code> headings for sections</li>
  <li><code>&lt;p&gt;</code> tags for explanations</li>
  <li><code>&lt;ul&gt;</code> for ingredients lists</li>
  <li><code>&lt;ol&gt;</code> for step-by-step cooking instructions</li>
</ul>

<h3>Vali Kebab Recipe</h3>

<p>
This page describes the traditional Vali Kebab, including an explanation,
ingredients list, and detailed cooking steps.
It demonstrates the use of images and structured content.
</p>

<h3>Billur Kebab Recipe</h3>

<p>
The Billur Kebab page explains a regional kebab variety.
It includes descriptive paragraphs, ingredients, and preparation steps,
showing how different content can still follow the same HTML layout.
</p>

<h3>Omelet Recipe</h3>

<p>
The omelet recipe page presents a simple and classic dish.
It focuses on clear instructions and minimal ingredients,
making it suitable for beginners.
</p>

<h2>Purpose of the Project</h2>

<p>
The main goal of this project is to practice:
</p>

<ul>
  <li>Basic HTML page structure</li>
  <li>Using headings, lists, and paragraphs correctly</li>
  <li>Linking multiple pages together</li>
  <li>Organizing files with folders</li>
  <li>Adding images with relative paths</li>
</ul>

<h2>Technologies Used</h2>

<ul>
  <li>HTML5</li>
</ul>

<p>
No CSS or JavaScript was used in this project.
</p>
